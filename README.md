# foxlift.dev

Source for the FoxLift launch site — an Astro static site deployed through
Cloudflare Workers Static Assets to [foxlift.dev](https://foxlift.dev).

```bash
npm install
npm run dev      # local dev server
npm run build    # astro check + build to dist/
npm run deploy   # build and publish with Wrangler
```

The product itself lives at [github.com/foxlift/foxlift](https://github.com/foxlift/foxlift).
